⚠️ Jangan boleh:
update role
Contoh controller:
async function updateMe(req, res, next) {
  try {
    const { account_name, full_name } = req.body;

    const { data, error } = await req.supabase
      .from("profiles")
      .update({
        account_name,
        full_name,
      })
      .eq("id", req.user.id)
      .select()
      .single();

    if (error) {
      throw new Error(error.message);
    }

    res.json({
      success: true,
      message: "Profile updated successfully",
      data,
    });
  } catch (err) {
    next(err);
  }
}

Route:

router.patch("/me", authMiddleware, authController.updateMe);

POST /api/threads/auto-post
Ini buat schedule dulu
Payload:
{
  "personaConfigId": "uuid-persona",
  "limit": 5,
  "scheduledAt": "2026-06-04T09:00:00+07:00"
}
Yang dilakukan:
bikin row di scheduled_jobs
isi job_type = threads_auto_post
isi schedule_type = once
isi schedule_value = scheduledAt
update content_outputs yang approved dan threads
set scheduled_at
set scheduled_job_id
POST /api/threads/auto-post/run
Ini buat jalanin job
Payload:
{
  "scheduledJobId": "uuid-job"
}
Yang dilakukan:
baca job dari scheduled_jobs
bikin row di scheduled_job_runs
ambil content_outputs yang sudah waktunya, urut scheduled_at ASC lalu created_at ASC
claim item dengan scheduled_job_run_id supaya nggak dobel
publish satu per satu ke Threads
sukses -> posted
gagal -> failed
